# Use este arquivo para iniciar novas sessões na IDE

===========================================================================
STACK
===========================================================================
Frontend : HTML + CSS + JavaScript (app.js, index.html, style.css)
Backend  : Windows Forms (.NET) + WebView2 (Chromium)
Dados    : Planilhas Excel via bridge C# <-> JS
URL      : https://app.local/index.html (Virtual Host, NÃO file://)
Bridge   : window.chrome.webview.hostObjects.bridge

===========================================================================
BRIDGE C# — PLANILHAS MAPEADAS
===========================================================================
'products'    → aba 'produtos'       cols: id,name,code,cost,price,stock,image,obs,category
'customers'   → aba 'clientes'       cols: id,name,whatsapp,email,obs,date,image
'sales'       → aba 'Planilha1'      cols: id,date,cliente,valor_total,desconto,valor_final,cost,lucro,pagamento,items
'settings'    → aba 'configuracoes'  cols: razao_social,responsavel,whatsapp,email,endereco,foto
'reversals'   → aba 'extornos'       cols: id,sale_id,product_id,product_name,qty,date
'users'       → aba 'usuarios'       cols: id,username,fullname,password,role,isDefaultCredential
'entradas'    → aba 'entradas'       cols: id,date,fornecedor,nota,obs,items,totalCusto
'fechamentos' → aba 'fechamentos'    cols: id,dataAbertura,dataFechamento,operador,valorAbertura,
                                          valorFechamento,totalVendasDinheiro,totalVendasCartao,
                                          totalVendasPix,totalGeral,diferenca,sangrias,suprimentos
'categories'  → aba 'categorias'     cols: id,name
'caixa'       → localStorage 'sv_caixa' (bridge não suporta — objeto complexo)

===========================================================================
PERSISTÊNCIA — PADRÃO salvarDados() / carregarDados()
===========================================================================
Bloco 1 — Promise.all (falha se qualquer um retornar false):
  products, customers, sales, settings, reversals,
  entradas, fechamentos, categories

Bloco 2 — try/catch individual com fallback localStorage:
  users   → localStorage 'sv_users'
  caixa   → localStorage 'sv_caixa'

Fallback total (sem bridge):
  localStorage: sv_products, sv_customers, sv_sales, sv_settings,
                sv_reversals, sv_users, sv_caixa, sv_fechamentos,
                sv_entradas, sv_categories

===========================================================================
NAVEGAÇÃO
===========================================================================
switchView(viewId) — views disponíveis e o que chamam ao entrar:
  dashboard      → renderDashboard()
  pos            → updatePOSCustomerList(), updatePOSProductList(), restaura posState
  caixa          → renderCaixa(), updateCaixaDot()
  products       → updateCategoryFilter(), renderProducts(query, category)
  customers      → renderCustomers()
  history        → renderHistory()
  entradas       → renderEntradas()
  settings       → renderSettings(), renderUsers(), switchSettingsSection('empresa')
  relatorio-caixa → renderRelatorioCaixa()   ← mais recente

forbiddenViews (operadores não acessam): ['products','settings','relatorio-caixa']

titles{} e tags{} estão DENTRO de switchView() — ao adicionar view nova,
sempre adicionar entrada nos dois objetos.

===========================================================================
MODAIS
===========================================================================
openModal(type) — todos os modais registrados via classList.toggle hidden:
  product, customer, stock, receipt-confirm, generic-confirm,
  generic-alert, tutorial, sale-details-modal, stock-alerts,
  confirm-remove-logo, backup, confirm-import-backup,

  editingId = null, tutorialStep = 0

  Lista hardcoded de modals[] para esconder — ao criar novo modal,
  sempre adicionar o ID nessa lista.

showAlert(title, msg, icon) → abre generic-alert-modal

===========================================================================
SEGURANÇA
===========================================================================
hashPassword(password, username):
  PBKDF2, salt = username.toLowerCase()+'_SV2024_'+username.length
  100k iterações, SHA-256, 256 bits → hex string
  Fallback SHA-256 simples para migração de senhas antigas

login() — lockoutInterval com contador regressivo em tempo real
resetSystemUsers() — salva localStorage ANTES do bridge, await SaveData, reload após

===========================================================================
CAIXA — FÓRMULA
===========================================================================
diferenca = valorContado - (valorAbertura + totalVendasDinheiro
            - somaSangrias + somaSuprimentos)

Impressão: fecharCaixa() e reimprimirFechamento() usam os mesmos IDs:
  #caixa-print-container > caixa-print-empresa, operador, abertura,
  fechamento, valor-inicial, dinheiro, cartao, pix, total-vendas,
  sangrias, suprimentos, esperado, contado, diferenca, rodape
Ativação: document.documentElement + document.body
          → classList.add('printing-caixa') → window.print()
